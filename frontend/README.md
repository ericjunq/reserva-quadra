# Front-end (Angular)

Front do Sistema de Reservas. Consome a API Laravel da raiz deste repositório e tem deploy próprio.

```bash
npm install
npm start        # http://localhost:4200 (a API precisa estar em http://localhost:8000)
npm test         # testes unitários (Vitest)
npm run build    # build de produção em dist/
```

A documentação completa (decisões, estrutura, identidade visual e regras) fica no [`README.md`](../README.md) da raiz, seção "Front-end".
